usage: fastbrowse [-h] [--version] [--start START] [--context CONTEXT]
                  [--cloud | --local] [--headed]
                  [--profile PROFILE] [--cloud-profile ID] [--cdp-url URL]
                  [--cdp-port PORT] [--attach] [--target-match PATTERN]
                  [--foreground] [--proxy-country CC]
                  [--viewport WIDTHxHEIGHT] [--authorize]
                  [--secret NAME=ENV_VAR[@ORIGIN]] [--bitwarden ITEM]
                  [--input NAME=VALUE] [--file PATH] [--max-steps MAX_STEPS]
                  [--max-dollars MAX_DOLLARS] [--downloads DOWNLOADS] [--json]
                  [--record FILE] [--recipe FILE] [--save-recipe FILE]
                  [--fetch] [--browser] [--extension]
                  [--extension-browser LABEL] [--desktop APP] [--trace FILE]
                  [--cursor | --no-cursor]
                  task

Run one browser task in your own Chrome through the fastbrowse extension.

positional arguments:
  task

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --start START         URL to open before the task starts; worked out from
                        the task if omitted
  --context CONTEXT     background the run may use but never treats as part of
                        the task, such as where the request came from
  --cloud               use Browser Use Cloud instead of the extension
  --local               use your own Chrome through the extension (the default)
  --headed              unsupported: local CLI browsing requires the extension
  --profile PROFILE     unsupported: use a profile with the extension installed
  --cloud-profile ID    a Browser Use Cloud profile to run signed in as
                        (requires --cloud)
  --cdp-url URL         unsupported in the CLI: use the SDK for CDP connections
  --cdp-port PORT       unsupported in the CLI: use the SDK for CDP connections
  --attach              attach to an existing page/window without creating a
                        new tab or closing it on exit
  --target-match PATTERN
                        substring match on page title or URL when attaching to
                        an existing window (implies --attach)
  --foreground          bring the run's tab and its browser window to the
                        front, to watch it; otherwise a visible window stays
                        in the background
  --proxy-country CC    country the cloud browser browses from, as Browser
                        Use's two-letter code, e.g. uk (default: us;
                        requires --cloud)
  --viewport WIDTHxHEIGHT
                        screen size requested from cloud Chrome (requires
                        --cloud); this does not
                        emulate mobile, touch, device scale, or user agent
  --authorize           allow irreversible actions without confirmation
  --secret NAME=ENV_VAR[@ORIGIN]
                        secret from an environment variable, scoped to ORIGIN
                        or the --start origin (repeatable)
  --bitwarden ITEM      type this vault login's username, password and
                        authenticator code (rbw, or an unlocked bw CLI)
  --input NAME=VALUE    a named value the task can refer to, typed into a field
                        by name, so a recipe types the next run's value
                        (repeatable)
  --file PATH           a local file the run may attach to a file input on the
                        page (repeatable)
  --max-steps MAX_STEPS
                        optional step limit (default: no step limit)
  --max-dollars MAX_DOLLARS
                        optional model-spend limit in USD, excluding browser
                        charges
  --downloads DOWNLOADS
                        directory for downloaded files
  --json                print the full result as JSON
  --recipe FILE         replay a saved run: Jev is offered each saved action
                        alone where its page and control match
  --save-recipe FILE    save the steps of a completed run as recipe JSON
  --record FILE         save a video of the run, ending on its answer (needs
                        ffmpeg)
  --fetch               never start a browser: a step that needs one ends the
                        run blocked
  --browser             start a browser from the first step, rather than reading
                        over HTTP until the run needs one
  --extension           run in your own Chrome (the default), signed in, through
                        the fastbrowse extension (see: fastbrowse extension
                        install)
  --extension-browser LABEL
                        which browser to use when the extension is connected
                        in more than one, by the label its popup shows
                        (implies --extension)
  --desktop APP         start the native desktop app APP (a command line) and
                        drive it instead of a browser, through deskpilot on
                        Hyprland, without moving your pointer or focus; it
                        closes when the run ends
  --trace FILE          append the run's trace to FILE as JSON lines, or - for
                        stderr: every model call with its purpose and timing,
                        which reader answered each read and why, and every
                        check's scores (also FASTBROWSE_TRACE)
  --cursor              bring the window to the front so the agent's cursor
                        is always drawn
  --no-cursor           do not draw the agent's cursor (by default it is
                        drawn over a visible Chrome with the Cua Driver on
                        Linux X11, and skipped where unsupported)
