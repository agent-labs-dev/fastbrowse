# Crediting contributors

Every change that fixes a reported bug, builds a feature someone asked for, or lands someone's code credits that
person twice:

- **In its changelog bullet**, at the end: "Thanks to X for reporting it", or "Thanks to X, who asked for it", with
  a link to the issue. Code is "Contributed by X in #N".
- **As a row in [CREDITS.md](../../CREDITS.md)**: who, what their report, request or code led to (with the issue or
  PR), and any note, such as a commit picked up in another PR.

Who counts and how to name them:

- People outside the team, on GitHub or on Product Hunt. Team members are not listed.
- A GitHub user by their handle, linked to their profile. A Product Hunt commenter by display name and handle,
  linked to their profile, since the launch page has no per-comment link.
- Only what is built. A report still open, or a request not taken up, is covered by the table's closing thanks
  until a change lands for it.
