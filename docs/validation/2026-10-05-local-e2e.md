# Hosted and corpus fixture validation

These are single-agent fixture checks, not an external benchmark or a comparison with another agent.
The first three campaigns run 32 local and mock tasks three times through real Chrome and live models.
The OpenRouter CLI check runs each task once. Every physical attempt is retained in the linked rows, including failures. Cost is model spend, not hosted
customer pricing. Time includes browser setup.

The local campaign uses gateway-only Jev and LLM routing. Its rows record the exact model names, clean
commit, run ID, task versions, grades, status, time and cost. Twelve expected safety stops are passes:
nine confirmation stops and three login stops. Completion alone does not decide the grade.

The first campaign has two portal-consent failures caused by the fixture runner dismissing the banner.
The corrected GitHub campaign has one infinite-scroll failure: its answer contained the right count,
but the run stopped without proving completion. That failure remains in the rows. The local campaign
has no failures. The OpenRouter CLI check also passes all tasks, but its working tree includes the CLI
fix under test, so it is integration evidence rather than a release score. These campaigns describe separate builds and are not pooled into one
score.

Reproduce the local campaign from commit `f041f3b4a984c11e77c0018eddbbbb7172ee4fa3`:

```sh
uv sync --all-extras
# Configure AI_GATEWAY_API_KEY; leave OPENROUTER_API_KEY and TYPESAFE_API_KEY unset for this route.
uv run python -m fastbrowse.evals.runner --suite local mock --repeat 3 --out artifacts/evals/fixtures.jsonl
```

A green fixture campaign establishes this harness's behavior. It does not establish hosted deployment
availability, broad web success, or an independently graded external-corpus score. External corpus rows
must identify the pinned corpus, task draw, grader and observed state. Ungraded runs remain ungraded.
The release comparison feed and README headline use the release publication gate described in
[the eval workflow](../agents/evals.md), not this validation report.

[The external corpus diagnostics](2026-10-05-corpus-diagnostic.md) retain the real capsule checks and
explain why they do not support a benchmark headline.
