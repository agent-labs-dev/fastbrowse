## Detector decisions and backlog

that initial scope. Two format markers preserve the browser expressions: Python appends snapshot mode arguments directly
and embeds capture inside parentheses. Biome otherwise removes snapshot parentheses and adds a capture
semicolon, causing runtime syntax errors. These markers cover the expression bodies too, so formatting
enforcement remains a gap; lint still runs over both scripts. No lint rule is disabled there. No detector baseline or sift suppression was added.
The two vendored Python helpers produce five Ruff RUF100 diagnostics and formatting differences. The user approved excluding
only those files from Ruff and its hooks so they remain identical to upstream.

workflow. Both remain visible. TypeScript's 156 diagnostics need DOM and injected-registry annotations;
